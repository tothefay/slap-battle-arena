# Slap Battle Arena

เกมตบกันออนไลน์ 2 คนแบบเรียลไทม์ (Node.js + Express + Socket.IO + Canvas 2D)
เซิร์ฟเวอร์เป็นผู้ตัดสินการตบ หลบ ป้องกัน คะแนน เวลา และผลแพ้ชนะทั้งหมด

## ติดตั้งและรัน
    npm install
    npm start
เปิด http://localhost:3000 ในสองแท็บ (หรือสองอุปกรณ์ในเครือข่ายเดียวกันผ่าน http://IP-เครื่อง:3000)

## ทดสอบ 2 คน
แท็บ 1: ใส่ชื่อ > สร้างห้อง > คัดลอกรหัส 6 หลัก
แท็บ 2: ใส่ชื่อ > เข้าร่วมห้อง > กรอกรหัส (หรือเปิดลิงก์ /?room=รหัส)
เจ้าของห้องกด "เริ่มเกม" ระบบนับถอยหลัง 3-2-1 และแข่ง 90 วินาที

## ปุ่มควบคุม
ตบ = J, หลบ = K, ป้องกัน = L, โจมตีพิเศษ = Space (ต้องเกจพลังเต็ม ได้จากการตบโดน) หรือกดปุ่มบนหน้าจอ

## นำขึ้นเซิร์ฟเวอร์ (ตัวอย่าง Render.com ใช้ฟรีได้)
1. อัปโหลดโปรเจกต์ขึ้น GitHub
2. Render > New > Web Service > เลือก repo
3. Build Command: `npm install` / Start Command: `npm start`
4. ได้ลิงก์ https://ชื่อ.onrender.com ส่งให้เพื่อนเล่นได้ทันที (รองรับ WebSocket และ HTTPS)
หมายเหตุ: แพ็กเกจฟรีจะหลับเมื่อไม่มีคนใช้ ครั้งแรกอาจโหลดช้า 30-60 วินาที
ไม่ต้องใช้ฐานข้อมูล ห้องเก็บในหน่วยความจำของเซิร์ฟเวอร์

## กติกา (แก้ได้ที่ server.js)
ตบโดน +10 / หลบสำเร็จ +5 / พิเศษโดน +20 / ตบพลาด 0 / ป้องกันสำเร็จ 60% ของการตบธรรมดา (พิเศษทะลุป้องกัน)
หากผู้เล่นหลุด ระบบรอเชื่อมต่อใหม่ 10 วินาที ถ้าไม่กลับมาจะแจ้งอีกฝ่ายและกลับห้องรอ
